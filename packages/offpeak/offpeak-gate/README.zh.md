# @deepseek-ai/dsh-offpeak-gate

[English](README.md) | 中文

错峰暂停闸门，宿主插件：当持久化设置 `ui-offpeak.enabled`（由 [ui-offpeak](../../client/ui-offpeak/README.md) 所有）开启且北京时间处于配置的高峰区间时，挂起每一个 `agent/pre-step` 瀑布决策。校验后的 Config 提供 `peakWindows`（默认 09:00–12:00、14:00–18:00，起点包含、终点不包含）和 `pollMs`。等待时间不会越过下一处时段边界，因此 11:59:59 仍暂停、12:00:00 立即续上，18:00 同理；暂停中关闭开关会在 `pollMs` 内生效。进行中的调用正常完成——不取消任何任务——步骤中止同样会释放挂起。宿主组合包含 settings 服务时，闸门在宿主侧注册 `ui-offpeak` 设置段；没有该服务时闸门保持打开。

## 模型体验

闸门只在新步骤开始前延迟进度，不改变内容：恢复时原样放行同一个下游决策，不替换模型供应商、模型、消息、工具或生成参数；已经开始的调用不会被打断。本插件不产生会话事件。
