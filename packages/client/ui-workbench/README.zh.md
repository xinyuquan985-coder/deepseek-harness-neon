# @deepseek-ai/dsh-client-ui-workbench

[English](README.md) | 中文

浏览器侧三工作台详情栏概览。本包填充由 [ui-conversation](../ui-conversation/README.md) 声明的 `conversation.details.overview` 插槽，根据当前视图与本轮工具展示数据自动派生「对话 / 代码执行 / 执行轨迹」工作台，并通过标准会话与列表 Hook 读取队列、后台任务、子代理和待处理交互数量。它不提供手动模式选择，也不为展示伪造业务数据。用户选中具体工具调用时，现有工具详情会暂时取代概览；从工具详情返回后恢复正确的派生概览。

默认对话工作台在真实投影存在时显示目标、待办、队列、后台作业、子代理、待处理交互与交付物。代码执行工作台增加当前 Turn 的变更清单，提供全部／已修改／已生成筛选、唯一文件路径、生命周期与结构化差异计数。即使存在代码变更，只要当前视图为轨迹，轨迹工作台仍优先，并显示选中请求以及真实协作／作业／交付物投影。协作栏先显示子代理再显示后台任务，每个真实子代理使用正式 C 角色图和统一的 82×80 斜切平角单线头像框；名称、活跃状态、导航与停止操作仍由真实投影和动作提供。`debate-vs` 视图中的真实正方、反方与裁判子代理复用完全相同的头像框，根据角色切换人物和强调色，同时保留子代理目录中的权威名称与状态。概览可以汇总待审批状态，但绝不渲染允许／拒绝控件；对话输入区仍是唯一权威入口。

## 模型体验

无模型可见表面：本包只投影已有浏览器运行时状态，不产生会话事件、提示词、工具定义或模型输入。

## 已知限制与延期工作

- **有意受投影限制** —— 目标、待办、后台作业、子代理、审批或文件不存在时，不会制造占位业务数据。
