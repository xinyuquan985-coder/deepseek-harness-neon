# @deepseek-ai/dsh-client-ui-offpeak

[English](README.md) | 中文

错峰模式，浏览器侧：输入框工具行开关（`conversation.input.right`）与输入框下方状态行，都受持久化设置 `ui-offpeak.enabled` 驱动。默认服务时段按北京时间判定：09:00–12:00、14:00–18:00 暂停新步骤，并分别在 12:00、18:00 整点续上；其余所有分钟均可运行。本包交付开关、共享调度逻辑与持久化设置；宿主侧暂停闸门消费同一设置命名空间。

## 模型体验

无模型可见表面：开关与状态行仅作展示，不产生会话事件。
