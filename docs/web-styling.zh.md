# Web UI 样式参考

[English](web-styling.md) | 中文

本文规定浏览器客户端包的样式职责归属与组件规则。当前 token 值位于 [`packages/client/ui-theme/src/styles/`](../packages/client/ui-theme/src/styles/)；本文不重复这份由源码生成的清单。

## 职责归属

[`ui-theme`](../packages/client/ui-theme/README.md) 负责 `--dsw-*` 静态色阶、语义别名、排版、动效、渐变、阴影、滚动条样式以及 `light`／`dark`／`system`／`cyber` 主题偏好。[`ui-layout`](../packages/client/ui-layout/README.md) 将解析后的主题快照应用到文档。功能包使用语义别名，不得另行定义全局主题。

全局样式表归 `ui-theme/src/styles/` 所有。组件样式以 CSS Modules 形式放在组件旁。当某个值属于该组件的布局或呈现约定时，组件可以定义局部自定义属性；共享颜色、排版、层级和动效属于主题包。

## 组件规则

- 使用 CSS Modules 和 `clsx`；不得添加组件库或 Tailwind。
- 功能组件使用 `--dsw-alias-*` 和共享的 `--dsw-specific-*` 语义 token。不得复制静态色板值或在其中写入颜色字面量。
- 明暗主题覆盖属于主题所有方。当默认声明保持主题中立，且门控规则只消费共享语义 token、不会定义第二套色板时，功能组件可以使用 `body[data-theme-id='cyber']` 门控 Cyber 专属构图。
- 字体大小必须与行高配对；已有角色匹配时使用主题排版变量。
- 当组件约定要求保留列结构时，源码文本、终端输出和 diff 行不得换行；使用共享滚动条样式，不得定义组件专用滚动条选择器。
- 呈现规则写在 CSS 中。React 内联样式可以传递组件局部自定义属性值，但不得编码主题分支。
- 添加过渡动画或仅悬停可见的控件时，保留清晰可见的键盘焦点和减少动态效果行为。

## 基于真实状态派生的 Cyber 工作台

Cyber 根据真实会话状态呈现三种工作台；它们不是主题、预设或手动模式。当前视图为 Trajectory 时始终选择轨迹工作台；否则，当前 Turn 出现写入／编辑等代码变更活动时选择代码执行工作台；仅搜索或读取仍保持对话工作台。多种证据同时存在时按此前置关系判定，避免为同一会话制造第二套状态。

无会话阶段是 Cyber 接入界面，不是第四种工作台。它可以在现有壳层后使用铺满区域的夜之城位图，但所有标签和交互控件都必须保留为组件中的真实标记；生产背景图不得把侧边栏、输入区或产品文案烘焙进像素。主题中立的默认声明要在 Cyber 之外隐藏该图，所有环境位移与扫描效果都必须为减少动态效果提供静态降级。

- **A — 默认对话：** 对话流加常驻任务控制概览。
- **B — 代码执行：** 同一壳层内使用紧凑的终端／差异／读取／搜索工具行和当前 Turn 变更清单。
- **C — 多智能体轨迹：** 使用执行轨迹标题带和可读的可选择事件清单／详情分栏，并汇总真实选中请求、子代理、后台作业、待处理交互和当前 Turn 交付物。协作栏先显示子代理再显示后台任务；角色图来自正式 C 设计稿，复用 A 的 82×80 斜切平角单线框，名称、状态和操作仍来自真实投影。

A 与 B 的对话角色几何保持一致。AI 身份区固定在消息框外左侧，用户身份区固定在消息框外右侧，二者使用相同的头像尺寸和斜切平角单线边框。功能或角色可以更换头像内容，但不得改变身份区尺寸、边框几何或所在侧；人物朝向需要向内时，只翻转肖像图片，不翻转边框、姓名或状态。代码工具行仍作为全宽清单行排列在这些左右镜像的对话轮次之间。

辩论检查栏对真实正方、反方和裁判子代理采用同一头像契约。角色可以切换 CG 人物以及黄／红／青强调色，但 82×80 单线斜切平角框、真实子代理名称、状态与可用操作不得改变。

共享壳层语义为 `--dsw-specific-workbench-chamfer`、`-rail-fill`、`-rail-border`、`-role-accent`、`-ledger-selected` 和 `-danger-outline`。它们拥有安全的浅色／深色默认值，`cyber-effects.css` 提供 Night City 覆盖值。黄色只表示当前动作或选择，青色表示运行状态，红色保留给风险与错误。审批的唯一响应入口仍是对话输入区接管；概览可以提示审批待处理，但不得新增第二套允许／拒绝按钮。

宿主验收使用正式 Web 组合，而不是裸 Vite 页面；覆盖 1920、1366、1024、1023、720 宽度，侧栏／详情栏自动让位、页面溢出、减少动态效果、关闭请求详情后的键盘焦点返回、控制台错误，以及 A/B/C 的可重放 ARIA 基准。

## 变更系统

在所属 `ui-theme` 样式表中添加或修改共享 token，然后在功能包中使用其语义别名。公共样式约定发生变化时，更新所属包的参考文档。视觉行为遵循[测试策略](testing.md)；[样式系统 Agent Note](../.agents/notes/implemented/process/2026-07-19-web-styling-system.md) 记录框架依据。
